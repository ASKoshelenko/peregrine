07 · Production posture

Cheap when idle. Bounded when busy. Explainable always.

Platform engineering is the set of constraints that remain true after the demo ends.

IDENTITYNo ambient project power

The runtime service account has no project roles. The model is bundled and fingerprint-checked at startup.

SUPPLY CHAINDigest, not a mutable tag

Terraform pins the exact container digest. Artifact Registry deletes untagged images after seven days.

COSTScale 0 → 1, never beyond

One CPU, 1 GiB, concurrency four, request-only CPU and no always-on instance.

FAILUREFail closed at every seam

Model hash mismatch blocks readiness; missing evidence renders a dash; failed gates block promotion.
